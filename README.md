# スーパーマーケット・シミュレーター 3D (Supermarket Simulator)

ご提示いただいた仕様書通りに作成された、ブラウザ上で動作する本格1人称視点(FPS)スーパーマーケット経営3Dシミュレーションゲームです。
軽量なThree.jsプロシージャル3Dエンジンを採用しており、低スペックPCでも滑らかに動作します。

---

## 🎮 起動方法

1. [index.html](file:///C:/Users/ueda/.gemini/antigravity/scratch/supermarket_sim/index.html) を任意のWebブラウザ（Chrome / Edge / Firefoxなど）で開くか、または [run_game.bat](file:///C:/Users/ueda/.gemini/antigravity/scratch/supermarket_sim/run_game.bat) をダブルクリックするだけで即座にプレイできます。

---

## 🕹️ 基本操作 (1人称視点 / WASD操作)

| 操作キー | アクション |
| :--- | :--- |
| **W / A / S / D** | プレイヤー移動 (前後左右) |
| **マウス移動** | 視点移動 (画面クリックでマウスロック、ESCで解除) |
| **E キー / 左クリック** | インタラクト (レジに入る、ダンボール箱を持つ、棚へ商品を陳列、管理PCを開く) |
| **右クリック** | 持っているダンボール箱を床に置く / 備品配置のキャンセル |
| **TAB キー** | 本部発注・店舗管理PCの開閉 |
| **R キー** | 備品配置モード中に棚やレジを90度回転 |

## 📋 仕様書の完全再現ポイント

### 1. カテゴリマスター
- **大カテゴリ**: デイリー、非デイリー、備品
- **中カテゴリ ＆ 商品群**:
  - **デイリー (要冷蔵・冷蔵棚専用)**:
    - **米飯**: おにぎり(ツナマヨ), おにぎり(しゃけ), おにぎり(昆布), 弁当(幕の内), 弁当(鮭), 弁当(のり弁)
    - **パン**: コッペパン(あんこ), コッペパン(ピーナッツ), アンパン, ホットドッグ, サンドイッチ(たまご), サンドイッチ(ハムレタス)
  - **非デイリー (常温・商品棚専用)**:
    - **お菓子**: ポテトチップス(うすしお), ポテトチップス(コンソメ), えびせん, チョコレート, クッキー, 芋けんぴ
    - **ドリンク**: 水, コーラ, サイダー, 緑茶, 麦茶, 紅茶
  - **備品**:
    - **商品棚(非デイリー専用)**: 3段スチール陳列棚
    - **冷蔵棚(デイリー専用)**: 青色LED照明付き冷蔵ショーケース
    - **レジカウンター**: POSレジスタデスク (最初から売場には置かれておらず、自分で購入して設置)

### 2. 客のロジック ＆ AI
- **客入店 → 棚からランダムに商品ピッキング → 会計 → 退店**
- **年代・職業・固定客/流動客ごとの購買差**:
  - **10代 学生**: スナック、炭酸、菓子パン、ツナマヨなど 1〜3個
  - **20代 会社員**: のり弁、鮭弁当、サンドイッチ、水・お茶など 2〜4個
  - **30代・40代 会社員**: 幕の内弁当、サンドイッチ、緑茶など 2〜4個
  - **30代・40代 主婦**: 家族用のパン複数、お菓子、麦茶、おにぎりなど 3〜6個
  - **50代・60代以上 シニア**: 鮭弁当、昆布おにぎり、緑茶、麦茶、芋けんぴなど 1〜3個
  - **固定客**: 購買点数が+1増加、満足度高
- **時間帯別ピーク**:
  - **開店～9時**: 出勤ラッシュ (高密度来客)
  - **11時～13時**: 昼ラッシュ (お弁当・サンドイッチ需要の最大ピーク)
  - **17時～19時**: 夕方ラッシュ (帰宅ピーク)
  - **22:00 (閉店時間)**: 新規レジ待ち客は増えず、残りの客が会計終了後に日次決算表示

### 3. レジシステム (POS)
- お客様がカゴをレジ台に置く
- **スキャン**: 1点スキャンするごとに、カゴ内の商品数が1つずつ減り、合計金額に加算 (ピピッ音)
- **会計する**: カゴが0になるとボタンが有効化 → 押すと「預り金」を受け取る
- **おつりを渡す**: お札・硬貨トレイから必要なおつりを選択して渡す → 売上に反映 ＆ レジチン音 ＆ 客退店

### 4. 配達・搬入システム（店の外にダンボール配送）
- **全発注品が店の外にダンボールで配達**:
  - デイリー商品・非デイリー商品だけでなく、**備品（商品棚、冷蔵棚、レジカウンター）もすべてダンボール箱に入った状態で店の外の歩道（配達受取エリア）に届きます**。
  - 外に出て <kbd>E</kbd> または <kbd>左クリック</kbd> で箱を持ち上げ、店内に搬入します。
  - 備品ダンボールを持った状態で店内に入り、<kbd>R</kbd> で向きを回転、<kbd>左クリック</kbd> で開封・設置できます。
  - <kbd>右クリック</kbd> で持っている箱を足元の床に一時的に置くことも可能です。

### 5. その他機能
- **初期売場**: 売場に棚もレジも置かれていない状態からスタート
- **時計**: ゲーム開始時は8:00で時計が停止した状態。「▶ 開店」ボタンでいつでも時間を進められます
- **チュートリアル**: 開始時に遊び方を分かりやすくガイドするモーダルが表示
- **スタッフ雇用**: 管理PCから「店員 田中さん」を雇用でき、店舗内にスタッフが可視化
