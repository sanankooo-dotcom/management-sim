# スーパーマーケット・シミュレーター 3D (Supermarket Simulator)

ご提示いただいた仕様書通りに作成された、ブラウザ上で動作する本格1人称視点(FPS)スーパーマーケット経営3Dシミュレーションゲームです。
軽量なThree.jsプロシージャル3Dエンジンを採用しており、低スペックPCでも滑らかに動作します。

---

## 🎮 起動方法

1. [index.html](file:///C:/Users/ueda/.gemini/antigravity/scratch/supermarket_sim/index.html) を任意のWebブラウザ（Chrome / Edge / Firefoxなど）で開くか、または [run_game.bat](file:///C:/Users/ueda/.gemini/antigravity/scratch/supermarket_sim/run_game.bat) をダブルクリックするだけで即座にプレイできます。

---

## 🕹️ 基本操作 (1人称視点 / WASD操作)

| 操作キー | アクション |
| :--- | :--- |
| **W / A / S / D** | プレイヤー移動 (前後左右) |
| **マウス移動** | 視点移動 (画面クリックでマウスロック、ESCで解除) |
| **E キー / 左クリック** | インタラクト (レジに入る、ダンボール箱を持つ、箱の開閉、棚へ1個陳列、管理PCを開く) |
| **右クリック** | 【棚を向いて】棚から商品を1個回収 / 【空間・床を向いて】ダンボール箱を床に置く / 備品配置のキャンセル |
| **Q キー** | 【ゴミ箱を向いて】空のダンボール箱をゴミ箱に廃棄・消去 |
| **TAB キー** | 本部発注・店舗管理PCの開閉 |
| **R キー** | 備品配置モード中に棚やレジ、ゴミ箱を90度回転 |

## 📋 仕様書の完全再現ポイント

### 1. カテゴリマスター
- **大カテゴリ**: デイリー、非デイリー、備品
- **中カテゴリ ＆ 商品群**:
  - **デイリー (要冷蔵・冷蔵棚専用)**:
    - **米飯**: おにぎり(ツナマヨ), おにぎり(しゃけ), おにぎり(昆布), 弁当(幕の内), 弁当(鮭), 弁当(のり弁)
    - **パン**: コッペパン(あんこ), コッペパン(ピーナッツ), アンパン, ホットドッグ, サンドイッチ(たまご), サンドイッチ(ハムレタス)
  - **非デイリー (常温・商品棚専用)**:
    - **お菓子**: ポテトチップス(うすしお), ポテトチップス(コンソメ), えびせん, チョコレート, クッキー, 芋けんぴ
    - **ドリンク**: 水, コーラ, サイダー, 緑茶, 麦茶, 紅茶
  - **備品**:
    - **商品棚(非デイリー専用)**: 3段スチール陳列棚
    - **冷蔵棚(デイリー専用)**: 青色LED照明付き冷蔵ショーケース
    - **ドリンク専用冷蔵庫(飲料専用)**: 透明ガラス扉・庫内クールLED冷光・電光看板を備えた飲料専用リーチインショーケース (容量18個)
    - **レジカウンター**: POSレジスタデスク (最初から売場には置かれておらず、自分で購入して設置)
    - **ゴミ箱(空き箱専用)**: 不要になった空のダンボール箱を投入して廃棄・消去できる業務用ダストボックス (自分で購入して店内の好きな位置に設置)

### 1.5 商品ライセンスシステム (カテゴリ別販売許可)
- 商品を発注するには、カテゴリー（ジャンル）ごとの**「販売ライセンス」**を購入してアンロックする必要があります。
- 管理PC（<kbd>TAB</kbd>）の「📜 商品ライセンス」タブ、または「デイリー商品」「非デイリー商品」タブの各見出しバナーからいつでも取得できます。
- **ライセンス一覧**:
  - **お菓子販売ライセンス** (¥4,000 / 常温・商品棚専用): スナック菓子、板チョコ、クッキーなど全6品
  - **ドリンク販売ライセンス** (¥6,000 / 常温・商品棚 or ドリンク冷蔵庫): 水、お茶、コーラ、サイダーなど全6品
  - **パン・ベーカリー販売ライセンス** (¥8,000 / 要冷蔵・冷蔵棚専用): コッペパン、アンパン、サンドイッチなど全6品
  - **米飯・特製弁当販売ライセンス** (¥12,000 / 要冷蔵・冷蔵棚専用): 人気おにぎり3種、幕の内・鮭・のり弁など全6品
- **直感的なUI/UX**:
  - ライセンス未取得のカテゴリー商品は「🔒 要: 〇〇ライセンス」とロック表示され誤発注を防止。
  - 各商品タブの上部バナーや商品カードからワンクリックでライセンスを即時取得可能。
  - セーブ＆ロードおよびオンラインマルチプレイ（リアルタイム共同経営）でのライセンス取得同期に完全対応。

### 2. 客のロジック ＆ AI
- **客入店 → 棚からランダムに商品ピッキング → 会計 → 退店**
- **年代・職業・固定客/流動客ごとの購買差**:
  - **10代 学生**: スナック、炭酸、菓子パン、ツナマヨなど 1〜3個
  - **20代 会社員**: のり弁、鮭弁当、サンドイッチ、水・お茶など 2〜4個
  - **30代・40代 会社員**: 幕の内弁当、サンドイッチ、緑茶など 2〜4個
  - **30代・40代 主婦**: 家族用のパン複数、お菓子、麦茶、おにぎりなど 3〜6個
  - **50代・60代以上 シニア**: 鮭弁当、昆布おにぎり、緑茶、麦茶、芋けんぴなど 1〜3個
  - **固定客**: 購買点数が+1増加、満足度高
- **時間帯別ピーク**:
  - **開店～9時**: 出勤ラッシュ (高密度来客)
  - **11時～13時**: 昼ラッシュ (お弁当・サンドイッチ需要の最大ピーク)
  - **17時～19時**: 夕方ラッシュ (帰宅ピーク)
  - **22:00 (閉店時間)**: 新規レジ待ち客は増えず、残りの客が会計終了後に日次決算表示

### 3. レジシステム (POS)
- お客様がカゴをレジ台に置く
- **スキャン**: 1点スキャンするごとに、カゴ内の商品数が1つずつ減り、合計金額に加算 (ピピッ音)
- **会計する**: カゴが0になるとボタンが有効化 → 押すと「預り金」を受け取る
- **おつりを渡す**: お札・硬貨トレイから必要なおつりを選択して渡す → 売上に反映 ＆ レジチン音 ＆ 客退店

### 4. 配達・搬入システム（店の外にダンボール配送）
- **全発注品が店の外にダンボールで配達**:
  - デイリー商品・非デイリー商品だけでなく、**備品（商品棚、冷蔵棚、レジカウンター）もすべてダンボール箱に入った状態で店の外の歩道（配達受取エリア）に届きます**。
  - 外に出て <kbd>E</kbd> または <kbd>左クリック</kbd> で箱を持ち上げ、店内に搬入します。
  - 備品ダンボールを持った状態で店内に入り、<kbd>R</kbd> で向きを回転、<kbd>左クリック</kbd> で開封・設置できます。
  - <kbd>右クリック</kbd> で持っている箱を足元の床に一時的に置くことも可能です。

### 5. その他機能
- **初期売場**: 売場に棚もレジも置かれていない状態からスタート
- **時計**: ゲーム開始時は8:00で時計が停止した状態。「▶ 開店」ボタンでいつでも時間を進められます
- **チュートリアル**: 開始時に遊び方を分かりやすくガイドするモーダルが表示
- **スタッフ雇用**: 管理PCから「店員 田中さん」を雇用でき、店舗内にスタッフが可視化
- **一人称手元モデル (FPS Viewmodel)**:
  - 画面下部にプレイヤー（店員）の腕・手元が常時表示
  - 通常時（手ぶら）はリラックスした構えで、移動時の歩行ボビングや視点移動のスウェイが連動
  - クリックや陳列、インタラクト時に手が前方に自然にリーチ・アクション
  - ダンボール箱所持時は、正面に商品名・残数ラベルが付いたダンボール箱を両手で抱えるポーズにスムーズに切り替わります
- **リアルなダンボール箱の開閉・陳列・回収システム**:
  - ダンボール箱を持った状態で左クリック（または <kbd>E</kbd>）すると、上面が**横方向（左右）だけにパカッと観音開き**し、プレイヤーの視点に向けて箱が手前に自然にチルトして内部に詰まった商品ミニチュア（おにぎり、弁当、ボトル、パン、スナック、備品パーツ）がハッキリと見えます
  - 手前や奥に余計なフラップがないため、見下ろし視界を遮らずに中身を鮮明に確認可能
  - もう一度クリックするとフラップがパタンと閉じます
  - テープ剥がし＋ダンボール開閉の専用効果音（Web Audio API）を再生
  - 棚への陳列は**箱が開いている状態でクリック1回ごとに商品を1個ずつ**棚に陳列でき、カチカチとテンポよく品出しするごとに箱の中のミニチュア商品と残数ラベルも1個ずつリアルタイムに減っていきます
  - 閉じた状態で棚をクリックした場合は、自動的に箱が開いて陳列準備が整います
  - **空箱の保持と棚からの商品回収（右クリック）**:
    - すべての商品を陳列しきっても箱は消えず、「空のダンボール箱」として手元に残り続けます
    - **開いた空箱（または同じ商品が入った箱）を持って棚を右クリック**すると、棚に並んでいる商品を**1個ずつ箱へ回収**できます
    - 回収するごとに箱のカウントが増加し、手元モデルの箱の中に商品ミニチュアが1個ずつ復活します
    - 棚以外の床や空間を向いて右クリックした場合は、通常通り空箱を床に置くことができます（床に置いた空箱はラベルが「📦 空のダンボール箱」となり、再び持ち上げて再利用可能）
    - セーブ＆ロードやオンラインマルチプレイでの回収・補充のリアルタイム同期にも完全対応しています
- **空き箱専用ゴミ箱（ダストボックス）＆廃棄システム**:
  - 管理PC（<kbd>TAB</kbd>）の備品タブから「ゴミ箱(空き箱専用)」（¥3,000）を発注できます
  - 他の備品と同様に屋外の配達エリアに大型ダンボールで届き、店内の自由な位置に向きを調整して配置できます
  - **空のダンボール箱を持った状態でゴミ箱を向いて <kbd>Q</kbd> キーを押す**と、リアルな潰し・廃棄効果音（Web Audio API）とともに空箱がダストボックスに吸い込まれて消去され、手ぶら状態に戻ります（クリック操作による誤廃棄を防止）
  - まだ商品が残っている箱や備品箱を誤って捨ててしまわないよう安全ガード（エラー警告音とトースト表示）が搭載されています
- **ドリンク専用冷蔵庫（リーチインショーケース）＆専門陳列システム**:
  - 管理PC（<kbd>TAB</kbd>）の備品タブから「ドリンク専用冷蔵庫(飲料専用)」（¥16,000）を発注・購入できます
  - 他の備品と同様に屋外の配達受取エリアに大型ダンボールで届き、店内に搬入して <kbd>R</kbd> キーで回転させながら好みの位置に配置可能
  - 下部機械室吸気グリル、背面・側面パネル、ワイヤーシェルフ3段、前面2枚透明ガラス扉、シルバーハンドル、頭上電光看板（「🧊 冷たいお飲み物 DRINK COOLER 🥤」）、庫内クールLED冷光（エメラルドシアン）をリアルに再現
  - **ドリンク商品専用**のため、飲料（水・コーラ・サイダー・緑茶・麦茶・紅茶）のみ陳列可能（最大18本）。他の商品（米飯・パン・お菓子）を陳列しようとすると警告案内が表示されます
  - ドリンク商品は通常の商品棚とドリンク専用冷蔵庫のどちらにも陳列可能です
  - 客AIも自動的にドリンク冷蔵庫を認識して好みのドリンクをピッキング購入し、セーブ＆ロードやオンラインマルチプレイ同期にも完全対応しています
